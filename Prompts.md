# Dev-Detective – Prompts Documentation

## Project Overview
Dev-Detective is a web application that allows users to search for GitHub profiles using a GitHub username. It displays profile information and the latest five public repositories using the GitHub REST API.

## Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API
- GitHub REST API

## AI Prompts Used

### Prompt 1: Project Structure
Help me build a GitHub user search application using HTML, CSS, and JavaScript.

### Prompt 2: Fetch API
Explain how to fetch GitHub user profile data using the JavaScript Fetch API.

### Prompt 3: DOM Manipulation
Help me display a user's avatar, name, bio, account creation date, and portfolio link dynamically using JavaScript.

### Prompt 4: Repository Display
Explain how to fetch and display the latest five GitHub repositories as clickable links.

### Prompt 5: Error Handling
Explain how to handle invalid usernames, HTTP errors, and network errors using try, catch, and finally.

### Prompt 6: Testing
Suggest test cases for valid usernames, invalid usernames, loading messages, and repository-fetching errors.

## Learning Outcomes
- Learned to use the Fetch API to request data.
- Practised async/await and error handling.
- Used DOM manipulation to display API data.
- Practised sorting arrays and displaying repository links.
