# Dev-Detective 

Dev-Detective is a web application that allows users to search for GitHub profiles by username. It displays profile information and the latest five public repositories using the GitHub REST API.

## Features

- Search GitHub users by username.
- Display profile avatar, name, bio, and account creation date.
- Show a portfolio link when available.
- Fetch and display the latest five public repositories.
- Handle invalid usernames and API errors.
- Display a loading message while fetching data.
- Responsive layout for desktop and mobile screens.

## Technologies Used

- HTML
- CSS
- JavaScript
- Fetch API
- GitHub REST API

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Enter a GitHub username and click **Search**.

## Project Files

- `index.html` — page structure.
- `style.css` — styling and responsive layout.
- `script.js` — API requests and dynamic page functionality.
- `Prompts.md` — AI prompts and assistance documentation.

## API

This project uses the public GitHub REST API to retrieve user profile and repository information.

## Learning Outcomes

This project provides practice with asynchronous JavaScript, Fetch API, JSON parsing, DOM manipulation, and error handling.
